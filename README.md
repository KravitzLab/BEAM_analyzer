# BEAM Interactive Analyzer

A free, browser-based tool for analyzing activity and circadian rhythms from BEAM devices. BEAM was developed by the [Wash U NeuroTech Hub](https://neurotechhub.wustl.edu/).

## Quick start

1. Open the [BEAM Analyzer](https://kravitzlab.github.io/BEAM_analyzer/).
2. Upload one or more BEAM CSV files or a ZIP archive.
3. Optionally upload a metadata key (CSV or Excel) or edit the key directly in the browser.
4. Select your grouping variables and recording duration.
5. Open the **Analysis** tab to explore plots, compare groups, and export results.

## Privacy

All data processing occurs locally in your browser. **Your data is never uploaded to a server.**
